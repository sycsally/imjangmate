# 나의 첫 배포

치원 바이브 실습용 템플릿입니다. 설치, 터미널, 코드 작성 모두 없어도 됩니다. 브라우저만 있으면 이 페이지를 내 계정으로 가져와 인터넷에 올리고 AI와 함께 나만의 앱으로 바꿀 수 있습니다.

## 시작하기 전에

세 곳에 가입해 둡니다.

1. [GitHub](https://github.com) 가입.
2. [Vercel](https://vercel.com) 가입. `Continue with GitHub`를 눌러 방금 만든 GitHub 계정으로 들어갑니다
3. [Claude](https://claude.ai) 가입. 쓰던 AI 채팅이 있으면 그것을 써도 됩니다

## 걸음 1. 내 주소 받기

아래 버튼을 누릅니다.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsycsally%2Fchiwonvibe-firstdeploy&repository-name=chiwon-myname)

1. 저장소 이름 칸의 `chiwon-myname`에서 `myname`을 내 영문 이름으로 바꿉니다. 예: `chiwon-gildong`
2. `Create`를 누르고 1분쯤 기다립니다
3. 축하 화면이 뜨면 끝입니다. `chiwon-내이름`으로 시작하는 주소가 생겼습니다. 같은 이름을 누가 먼저 썼다면 뒤에 글자가 더 붙는데, 그게 정상입니다. 

방금 일어난 일: 이 템플릿이 내 GitHub 계정에 복제됐고, Vercel이 그것을 인터넷에 올렸습니다.

## 걸음 2. 내 자기소개로 바꾸기

1. [github.com](https://github.com)에서 방금 생긴 내 저장소(`chiwon-내이름`)를 엽니다
2. `index.html`을 누르고 오른쪽 위 연필 아이콘을 누릅니다
3. `✏️ 실습 0`~`✏️ 실습 3` 표시를 찾아 이름, 나이, 소속, 한 줄 소개를 내 것으로 바꿉니다
4. 오른쪽 위 `Commit changes...`를 누르고, 한 번 더 `Commit changes`를 누릅니다
5. 1분 뒤 내 주소를 새로고침합니다. 자기소개가 바뀌어 있습니다

방금 일어난 일: 저장(커밋)을 했더니 Vercel이 알아서 다시 올렸습니다.

## 걸음 3. 나만의 밸런스 게임 만들기

자기소개 아래 `밸런스 게임 시작하기` 버튼을 누르면 질문 5개가 하나씩 나오고, 다 풀면 나와의 싱크로율이 나옵니다. 질문과 내 답을 바꿔 봅니다.

1. 다시 `index.html`의 연필 아이콘을 누릅니다
2. `✏️ 실습 4`를 찾아 질문(`<h2>`)과 보기 두 개(`<button>`)를 내 것으로 바꿉니다
3. 각 질문의 `data-my-answer="A"`를 내가 고르는 쪽(`A` 또는 `B`)으로 적습니다
4. `✏️ 실습 5`에서 점수별 한마디도 바꿔 봅니다
5. `Commit changes`를 누르고 1분 뒤 새로고침한 다음, 직접 풀어 봅니다
6. 내 주소를 단톡방에 올리고 다른 사람 게임도 풀어 봅니다

질문이 떠오르지 않으면 Claude에게 “대학생이 공감할 밸런스 게임 질문 5개를 A vs B 형태로 추천해 줘”라고 물어보세요.

여유가 있으면 `style.css`의 `✏️ 실습 7`(색), `✏️ 실습 8`(글자 크기·둥글기)도 바꿔 봅니다.

## 걸음 4. AI로 나만의 앱 만들기

자기소개 페이지는 그대로 두고, 앱은 새 저장소에 만듭니다.

1. 이 페이지 위쪽의 `Deploy` 버튼을 한 번 더 누릅니다
2. 저장소 이름을 `chiwon-myname-app`처럼 걸음 1과 다르게 짓고 `Create`를 누릅니다
3. 새로 생긴 저장소(`chiwon-내이름-app`)의 `index.html`과 `style.css` 내용을 각각 복사해 둡니다
4. Claude에 두 파일을 붙여넣고 이렇게 부탁합니다

   > 이 페이지를 (만들고 싶은 앱)으로 바꿔 줘. (누가) 쓰는 앱이고, (무엇을) 할 수 있으면 좋겠어. 휴대폰에서도 잘 보이게, index.html과 style.css 두 파일로 나눠서 각각 전체 코드를 줘.

5. 받은 코드를 새 저장소의 `index.html`과 `style.css`에 각각 덮어씁니다(연필 → 전체 선택 → 붙여넣기)
6. `Commit changes`를 누르고 1분 뒤 새 주소를 새로고침합니다

마음에 안 들면 Claude에게 "글씨를 더 크게", "버튼 색을 파란색으로"처럼 한 가지씩 다시 부탁하고 같은 방법으로 덮어씁니다.

뭘 만들지 모르겠다면 이 중에서 골라 보세요.

- 오늘 점심 메뉴 랜덤 추천기
- 시험이나 여행까지 남은 날을 세는 디데이 카운터
- 친구들끼리 푸는 나에 대한 퀴즈
- 집중용 뽀모도로 타이머

로그인, 회원 정보 저장, 결제처럼 서버가 필요한 기능은 오늘은 빼 둡니다.

## 막혔을 때

- 걸음 1에서 GitHub 연결 화면이 나오면 `Install`을 눌러 허용합니다
- 주소를 열었는데 예전 화면이면 1분 더 기다렸다가 새로고침합니다
- 배포가 실패하면 Vercel의 `Deployments`에서 로그를 통째로 복사해 Claude에게 붙입니다
- 망쳤다 싶으면 걱정하지 않아도 됩니다. GitHub는 모든 저장을 기억하고 있어서 `index.html`의 `History`에서 예전 내용을 볼 수 있습니다

## 이 저장소에 들어 있는 것

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 페이지의 내용(자기소개, 밸런스 게임 질문). `✏️ 실습` 표시가 있는 곳을 고칩니다 |
| `style.css` | 페이지의 생김새(색, 글자 크기). `index.html`이 불러와서 함께 적용됩니다 |
| `README.md` | 지금 읽고 있는 안내문 |
